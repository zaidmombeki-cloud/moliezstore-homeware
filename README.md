# Moliez Store Homeware v2

This is the improved static website package.

## Included
- Responsive customer website
- SEO-ready title and meta description
- WhatsApp ordering
- Welcome offer code: WELCOME10
- `/admin/` dashboard prototype for managing products in the browser

## Important
The current admin product data uses browser localStorage. It is a working prototype, but it is NOT a secure multi-user production CMS. For the final production system, connect the admin to a real database and authentication (for example via a Vercel-managed database/auth provider) before using it for real customer/order data.

## Deploy
Upload this folder to a Vercel project or import it into GitHub and deploy with Vercel.
